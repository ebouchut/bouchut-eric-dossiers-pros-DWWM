Introduction

Le besoin

  • Contexte: Apprendre à programmer suppose un parcours structuré :
    • du contenu organisé,
    • une progression lisible,
    • un espace où un formateur publie et fait évoluer ses cours.
  • Problème : offrir un environnement multi-rôles simple, sûr et accessible.
  • Solution :

    learn-dev est une plateforme Web où des formateurs publient des cours composés de leçons en Markdown, et où des étudiants s’inscrivent et les suivent.

Vue d’ensemble de learn-dev

  • Trois rôles :
    • étudiant (STUDENT), rôle par défaut
    • formateur (INSTRUCTOR)
    • administrateur (ADMIN)

`—

- **`STUDENT`** (étudiant) : - consultation du **catalogue**, - inscription à des **cours**, - lecture des **leçons**. - **`INSTRUCTOR`** (formateur) : - **création de contenu** (cours/leçons), - cycle de vie de **publication**, - gestion des **inscriptions**. - **administrateur** (`ADMIN`) : - gestion des comptes, - modération des contenus.

Base de données — MLD

Modèle Logique de Données

  • Indépendant de la base de données
  • Structure relationnelle partielle
    • tables
    • tables de jointure
      • modélisent la cardinalité N,N
    • clé étrangères (Foreign Keys)
      • précédées par #
      • modélisent les cardinalités 1,1 et 1,N

Base de données — MPD

Modèle Physique de Données

  • Syntaxe spécifique au moteur de base de données relationelle (SGBDR)
  • PostgreSQL (ADR-06),
  • Clés primaires (choix d’architecture ADR-03)
    • UUID pour la table users
      • anti-IDOR
      • dans les 10 principales vulnérabilités OWASP
    • BIGINT pour les autres tables
    • Clé primaire composite pour les 2 tables de jonction

Architecture en couches

MVC (Controller Model View)

  • Controller reçoit les requêtes HTTP entrantes et dispatche leur traitement et renvoie la réponse
    • Service applique les règles métier d’une entité.
      • Repository fait les interactions avec la base de données pour une entité.

# Accès aux données <small>(CP6)</small>

- **Spring Data JPA** : *repositories* = interfaces, requêtes **dérivées** et
  **paramétrées** (anti-injection SQL) ; `@Transactional`.
- **NoSQL** : MongoDB **provisionné** en vue d'un stockage de contenu (non encore branché).

```java
public interface UserRepository extends JpaRepository<User, UUID> {

    @EntityGraph(attributePaths = "roles")   // l'utilisateur ET ses rôles en 1 requête
    Optional<User> findByUsername(String username);

    boolean existsByUsername(String username);
    boolean existsByEmail(String email);
}

Sécurité

- **BCrypt**, **CSRF** activé, **anti-XSS** (jsoup). - **Anti-IDOR** (UUID), **anti-énumération**, **verrouillage de compte**, **rate-limiting**. - Jetons **hachés SHA-256**, **journal d'audit**, matrice d'autorisations **testée**. - Référence **OWASP Top 10** ; veille **Semgrep**.
```mermaid { scale: 0.55 } sequenceDiagram actor U as Navigateur participant S as Spring Security participant DB as PostgreSQL U->>S: POST /auth/login (+ jeton CSRF) S->>DB: charge utilisateur + rôles S->>S: vérifie le hash BCrypt alt échec S-->>U: 302 /auth/login?error else succès S-->>U: 302 /dashboard + Set-Cookie JSESSIONID
(HttpOnly, SameSite=Lax) end ```
